# How a circle uses this (one page)

1. **One organizer** creates the circle and writes the first practice note.
2. **Invite others** with the invite code on the circle page — joiners set a
   short trust profile (display name, how I show up, optional tag).
3. **Write practices** as they come up: situation, steps, never-promise,
   access notes, contact. Choose a carrier and a handoff date.
4. **Carry it forward**: the carrier owns the next visit. When work moves,
   the new carrier clicks "Mark handoff received" — the note keeps its text,
   the carrier and date update.
5. **Watch the carrying list** ("Who is carrying what") so nothing lives in
   one head.
6. **Edit or archive** notes as reality changes. Archived notes leave the
   carrying list but stay in the record.
